# Jai Jain | Digital Growth Systems

This repository contains the source code for my professional portfolio. 
Designed with a **minimalist, premium aesthetic**, this project showcases the 
intersection of high-performance web development and data-driven marketing strategy.

### 🚀 Core Features
* **Performance First:** Built for sub-second load times and optimized for Core Web Vitals.
* **Modern UI/UX:** Utilizing glassmorphism, fluid typography (Inter/Poppins), and responsive grids.
* **Technical SEO:** Engineered for maximum search visibility with structured data and clean hierarchy.
* **Project Ecosystem:** Showcasing live deployments in Fintech, EdTech, and Digital Journalism.

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Properties), JavaScript (ES6+), React.js
* **Optimization:** Technical SEO, GA4 Tracking, PageSpeed Optimization
* **Deployment:** GitHub Pages & Hostinger DNS Management
